# PixelSurgeon

**点中按钮，看清 CSS 差异，再决定要不要改。**

“把这个按钮改成紫色圆角。”这句话落到代码里，到底会动哪几行？
PixelSurgeon 把页面、修改要求和文件差异摆在同一个编辑台。先选中元素、预览补丁，再应用到本地文件；不喜欢，就撤销。

![页面画布、属性检查器与 CSS 差异抽屉在同一编辑台中](docs/images/editor-overview.png)

### 从一句要求，到一个看得见的修改

你可以用它体验可视化改样式的完整过程：看原页面 → 看 CSS diff → 写入文件 → 比较前后截图。前端教学、工具原型演示，或讨论“自然语言修改应该怎样让人审阅”，都能从这个小例子开始。

**当前只支持内置 Orbit 示例的一个按钮预设。** 没有接入 AI，要求由固定规则解析；不是任意网页编辑器。

### 在本机打开

准备 **Node.js 24 LTS** 与 npm（也支持 22.12+ 的 22 系列及 26+；不支持 23/25），然后运行：

```sh
git clone https://github.com/shenyangs/pixel-surgeon.git
cd pixel-surgeon
npm run setup
npm run doctor
npm run dev
```

浏览器打开 [http://127.0.0.1:4203](http://127.0.0.1:4203)，终端保持运行；结束时按 Ctrl+C。首次 setup 会联网安装依赖与测试浏览器，下载时间取决于网络。安装问题见 [使用手册](docs/usage.md)。

### 亲手改一次，再撤销

1. 点击画布里的 **开始创作**，选中 `.hero-cta`。
2. 保留“把按钮改为紫色圆角”，点击 **生成预设**，先读下方 CSS 差异。此时文件还没改。
3. 点击 **应用补丁**。按钮变色、圆角生效，真实修改前后截图出现。
4. 刷新页面确认效果还在，再点 **撤销**，恢复原来的 CSS。

![应用后出现紫色圆角按钮、CSS 差异，以及真实前后截图](docs/images/editor-result.png)

变化会写进 `fixtures/demo-site/src/theme-overrides.css`，不是只给预览套一层临时样式。你也可以打开这个文件，核对界面显示的 diff。

### 一次小修改，边界要清楚

只允许修改上述文件中的 `.hero-cta`，属性和值都有白名单；不接受任意路径、脚本或命令。预设五分钟后失效，期间文件变动也需重新生成。

撤销保留一份 CSS 快照，没有多级历史。若写入后截图失败，样式可能已经改好，可修复服务后刷新或撤销。当前没有网站导入、视觉评分或生产部署功能。

### 想继续看代码或验证结果

本地构建、单元测试、浏览器流程和演示录屏已经在 macOS 通过；README 配图来自实际运行的应用。Windows / Linux 实机与全新机器完整安装尚未验证。所有服务仅监听本机，没有部署所需的账号与鉴权，请勿直接暴露到公网。

停止开发服务后，可自行运行：

```sh
npm run build
npm run test
npm run e2e
npm run demo
```
